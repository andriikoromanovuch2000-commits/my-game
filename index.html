👤 Online account

Create an account with a made-up username and a unique password to back up your game online. No email or real name. Firebase Realtime Database stores your username, salted password hash, friend list, and game save; it never stores your plain-text password. Use a password you do not use anywhere else, never share it, and do not enter a real name. Signing in replaces this browser's save with the account's Firebase save. Password reset is not available yet. Online races use a direct peer-to-peer connection: the room creator's device hosts the race, while the game service only handles accounts, lobby discovery, and connection setup. The owner admin panel requires the server's ADMIN_PLAYER_ID to be set to the owner's player ID. For a local test, an adult can run npm install and npm start after configuring the Firebase Admin service-account credential, Realtime Database URL, and optional ADMIN_PLAYER_ID for the server, then open http://localhost:3000. Never put the service-account credential in the browser or commit it. Public hosting must use HTTPS and needs an adult to set it up; the server must only trust x-forwarded-proto when it comes from that trusted HTTPS proxy.
